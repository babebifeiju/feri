Yuki Art Studio ♡ Supabase Converter

เครื่องมือนี้แปลงไฟล์ index.html เดิมของ Yuki Art Studio เป็นเวอร์ชันเชื่อม Supabase โดยรักษาหน้าตาเว็บเดิม และสร้างผลลัพธ์เป็นไฟล์ HTML เพียงไฟล์เดียว

1. เลือกไฟล์ index.html ต้นฉบับ

ไฟล์จะถูกประมวลผลบนอุปกรณ์ของคุณ ไม่อัปโหลดออกไปที่เซิร์ฟเวอร์ใด ๆ

รอเลือกไฟล์ index.html

ขั้นตอนหลังสร้างไฟล์

  1. ดาวน์โหลดไฟล์ index.html ใหม่
  2. เปิด GitHub Repository babebifeiju/feri
  3. เปิด index.html แล้วใช้ Edit หรือ Upload files เพื่อแทนไฟล์เดิม
  4. Commit changes และรอให้เว็บไซต์ Deploy
  5. ทดสอบการเข้าเว็บ รีวิว และล็อกอินด้วยอีเมล/รหัสผ่าน Supabase

คำเตือน: ข้อมูลเก่าที่บันทึกเฉพาะใน localStorage บนอุปกรณ์เดิมจะไม่ถูกอัปโหลดโดยอัตโนมัติ เก็บไฟล์ต้นฉบับไว้ก่อนเสมอ
